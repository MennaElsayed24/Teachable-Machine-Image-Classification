# Teachable Machine Image Classification

An AI image classification project built using Google Teachable Machine. The model uses webcam images to distinguish between three different objects: Mobile, Book, and Cup.

## Project Overview

The goal of this project is to create an image classification model that can recognize and differentiate between multiple objects using a webcam.

## Classes

The model was trained to classify:

- Mobile
- Book
- Camera

## Dataset

At least 20 images were collected for each class.

The dataset included different:

- Angles
- Distances
- Lighting conditions
- Backgrounds
- Object positions

Additional images were added later to improve the model's performance and reduce incorrect predictions.

## Model Training

The model was trained using **Google Teachable Machine – Image Project**.

After collecting and organizing the images, the model was trained and tested using the webcam.

## Testing & Accuracy

During the initial testing, the model made approximately 4–5 incorrect predictions out of around 30 tests.

After increasing the number and variety of training images and retraining the model, the number of incorrect predictions decreased to approximately 1–2 out of around 30 tests.

This resulted in an estimated accuracy improvement from approximately **83–87%** to **93–97%**.

> Note: The accuracy is an estimated result based on manual webcam testing.

## Problems Faced

Some incorrect predictions occurred because of:

- Different lighting conditions
- Different object angles
- Different distances from the camera
- Background changes
- Limited training data in some situations

## How Accuracy Was Improved

The model performance was improved by:

1. Increasing the number of training images.
2. Using different angles and positions.
3. Using different lighting conditions.
4. Using different backgrounds and distances.
5. Retraining the model with the improved dataset.
